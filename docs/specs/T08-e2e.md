# T08 · 本地全链路验收（P0 收口）

## 1. 目标与范围

**做**：本地 compose 起全栈（PG/etcd/Kafka/网关/cs×2/persist/deliver/ghost），脚本化验收：
注册→登录（token+ws_addr）→双用户连**不同 CS**→A 发消息→B 实时收到→A 收 ACK→PG 落库→同 cli_msg_id 重放不重复。
配套交付（提前于 T17 落地，T17 仅剩文档）：`deploy/local/docker-compose.yml`、`tools/e2e`、Makefile、新 entrypoint 角色模型、alpine 运行时镜像。

## 2. 部署物（§4 规格对照）

- postgres:15（数据卷 + migrate 一次性容器跑 goose）· etcd 单节点 · kafka 单 broker（heap 512m，topic 显式创建：chat.msg/push 12P、fanout/ack 6P、notify 3P）
- gateway×1 · persist×1 · deliver×1 · ghost×1 · **joker×2**
- 双 joker 宿主机端口：cs-1 `37002/37012`、cs-2 `37202/37212`；`advertise_host=127.0.0.1`（浏览器直连）+ `grpc_advertise_host=cs-N`（deliver 内网拨接）——对外/对内地址解耦
- healthcheck + depends_on.condition 全链就绪编排

## 3. 验收记录（真实输出粘贴）

```
$ go run ./tools/e2e -gateway http://127.0.0.1:37001
== register two users
== login A (get ws_addr + token)
== login B until different chat server
  A -> 127.0.0.1:37202, B -> 127.0.0.1:37002 (cross-CS verified)
== open websockets to different chat servers
== A creates conversation with B
== A sends message (cli_msg_id=e2e-msg-1)
== B receives message frame in real time
  B received: conv=55743034-... seq=1 from=6523bb97-...
== A receives ack (delivered)
  A ack: msg_id=b27995a6-... seq=1
== replay same cli_msg_id (idempotency)
  (at-least-once duplicate push seen: {...same msg_id...})
== history shows exactly one row (replay not duplicated)
  PG row: msg_id=b27995a6-... seq=1 content={"text":"hello cross-cs"}
E2E PASS: register/login/ws_addr/cross-cs deliver/ack/persist/replay-idempotent
```

直接 PG 验证：
```
messages: conv=55743034-... | seq=1 | single | hello cross-cs
连接期 kv:  online:f98d8a17-... = {"cs":"127.0.0.1:37002","ts":...,"addr":"cs-1:37012"}
断开后:     SELECT count(*) FROM kv WHERE k LIKE 'online:%' → 0
```
etcd 服务表：`services/{uuid} → 127.0.0.1:37002 / 127.0.0.1:37202`，gateway 5s 刷新可见。

门禁：gofmt 空 / vet 0 / build ok / go test 7 包全绿。

## 4. 修复记录（验收过程中暴露）

1. cmd/brave.go 出错退出码 0 → compose `service_completed_successfully` 失效，改为 os.Exit(1)。
2. migrate 角色渲染错模板（migration 子命令读 brave.yaml 非 worker.yaml）。
3. joker 模板 etcd endpoints 残留旧同容器地址 127.0.0.1。
4. Dockerfile 缺 database/（goose 脚本）与 template/（LoadHTMLGlob）拷贝。
5. 运行时镜像 debian→alpine（etcd 已独立容器，glibc 约束解除；docker.io 拉取被重置，经镜像仓库取 alpine）。
